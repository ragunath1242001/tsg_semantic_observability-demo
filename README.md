# TNO Security Gateway

<div align="center">

![TNO logo](apps/control-plane-ui/public/layout/images/logo-dark.svg)

</div>

This is the repository of the Dataspace Protocol implementation of TNO, called the TNO Security Gateway (TSG). This repository is set up as a `pnpm` monorepo. It contains the apps `wallet`, `control plane` and `http data plane`. This allows users of the TSG to share data/participate in a dataspace according to the [Dataspace Protocol](https://docs.internationaldataspaces.org/ids-knowledgebase/v/dataspace-protocol). Identity is managed by the `wallet` component, and is an SSI implementation which is a [protocol that is under development right now](https://projects.eclipse.org/projects/technology.dataspace-dcp).
